# Traducción de RSL_Helper al Español

## Instrucciones de instalación

1. **Extraer y copiar archivos**  
   Extrae la carpeta comprimida de "RSL_Helper" y pégala en la ruta `C:\Program Files`, reemplazando los archivos existentes si el sistema lo solicita.

2. **Acceder a la configuración**  
   Abre **RSL_Helper** y dirígete al menú de **Configuraciones** (Settings).  
   ![Configuración](https://github.com/user-attachments/assets/73a0da5d-4d52-4d1f-9c4c-38cb219e9c80)

3. **Cambiar el idioma**  
   Ve a la pestaña **General** y haz clic sobre la opción de idioma (*English*) hasta que cambie a **ES**.  
   ![Selección de idioma](https://github.com/user-attachments/assets/eeb3c5d7-b78a-4674-8fa7-ebfb0400da5e)

4. **Confirmar el reinicio**  
   Aparecerá una ventana flotante solicitando reiniciar la aplicación. Haz clic en **Ja** (*"Sí"* en alemán) para confirmar y aplicar el cambio.  
   ![Confirmar reinicio](https://github.com/user-attachments/assets/ed2bb749-1a0f-4632-9bfe-3309ed78efb1)
